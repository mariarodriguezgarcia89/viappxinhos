# viAppxiños

App web privada para organizar viajes en grupo: itinerario compartido, alojamiento y lista de equipaje en un mismo sitio.

🚧 **Estado:** en desarrollo. MVP previsto para noviembre de 2026.

## Funcionalidades del MVP
- Registro e inicio de sesión
- Crear viajes y unirse a ellos con un código de invitación
- Itinerario por días: actividades con tipo (tour, restaurante, museo…) y enlace de reserva
- Alojamiento: enlace de la reserva, dirección y fechas
- Lista de equipaje compartida

## Próximamente
- Gastos compartidos, votaciones, billetes de avión y tren, álbum de fotos, playlist y mapa del viaje
